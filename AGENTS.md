# Работа с ELMA Wiki

Это самостоятельный Node.js-сервис. Начните с README.md и lib/e365.mjs.
Не используйте данные или credentials из родительских каталогов.

- В Git допустимы только код, универсальная документация и синтетические fixtures.
- dist/data.json должен оставаться пустым; импортированные индексы — только .local.
- Не коммитьте .env, OAuth-токены, архивы конфигураций или реальные примеры.
- Внешняя сеть приложения ограничена GitHub OAuth/API; не добавляйте live-подключения.
- Проверяйте владельца портала для каждого API и data.json, не полагайтесь на UUID.
- Не исполняйте загруженный код; извлекайте metadata по allowlist.
- UI на русском. Сохраняйте ограничения ZIP, границы окружений и атомарность импорта.
- npm test и npm run verify перед синхронизацией с origin.
- Не переносите .openai/hosting.json и identity другого сайта.
