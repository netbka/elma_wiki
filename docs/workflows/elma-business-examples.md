# Учебные бизнес-сценарии ELMA

Эти сценарии показывают формат полной функции для аналитика и бизнеса. Они не загружают клиентские конфигурации и не доказывают состояние DEV, dev2 или PROD.

## Согласование без повторной задачи

Исследовать: идентичность согласующего, версию документа, положительное решение, возврат, состав следующих этапов и журнал причины. Пример предполагает, что решение руководителя можно засчитать тому же человеку на следующем этапе для неизменённой версии. Другие участники продолжают маршрут. Доработка требует нового решения.

Критерии: повторная задача не создаётся при совпадении человека и согласованной версии; отказ не засчитывается; изменение версии снимает прежнее основание; причина видна в журнале. В конкретном решении проверьте реальные процессы договоров/доверенностей, права и уже запущенные экземпляры.

## Тематика исходящего во входящем

Исследовать: обе стороны связи, тип регулятора, флаг fill_investigate, источник subject, права, несколько исходящих и очередность событий. В примере подходящее исходящее с флагом «Да» даёт копию тематики для карточки/канбана. Снятие флага или связи очищает устаревшее значение.

Критерии: значение берётся из тематики; пустое значение объясняется; очистка выполняется; повтор не даёт дублей. Для конфигурации проверьте справочники, объединение связей, создание/удаление, смену регулятора, несколько исходящих, права и гонки. Учебная модель не реализует серверные обработчики.
