## Предложения из PR #7–#9

| Документ | Что определяет | Граница |
|---|---|---|
| [Developer workflow](DEVELOPER_VALUE_WORKFLOW.md) — PR #7 | Задачи пользователя, Designer-first, практические инструкции | Основной маршрут для текущего viewer; редактор и tutorial требуют реализации |
| [Browser workspace](WEB_DEVELOPER_WORKSPACE.md) — PR #8 | Редактор поддержанного кода, проверки, checkpoints, будущий bridge | Расширяет #7; будущая landing применяется после подтверждения возможностей |
| [Source/Target gateway](SOURCE_TARGET_GATEWAY_AND_ENGINEERING_SYSTEM.md) — PR #9 | Раздельные соединения, snapshots, candidates, read-back evidence | Целевая архитектура; текущие ограничения сети и deployment остаются действующими |

PR #8 уже включает документ из #7. Все три предложения объединены локально; отдельная реализация #8 добавляет экспериментальный browser editor с ограниченными типами и TypeScript-проверкой. Source/Target runtime не подключён. Английские архитектурные заметки не меняют русский язык пользовательского интерфейса.

При реализации обновляйте текущий статус по фактическим проверкам. Новые Product Constitution и Principles должны быть ELMA-specific; отдельная задача не считается выполненной включением архитектурной заметки.
