Или подключите репозиторий GitHub

Укажите репозиторий с .e365 либо извлечённой конфигурацией: package.json и папки сервисов с manifest.json. Сервис читает только выбранную конфигурацию.

Для закрытых репозиториев OAuth запрашивает scope repo: разрешение GitHub шире используемых сервисом операций чтения. Выданный токен хранится только в памяти сервера.
